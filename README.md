# Smart Attendance System

A web-based Smart Attendance System developed using Python and Flask to simplify attendance management. The application allows users to record, manage, and view attendance records through a simple web interface.

---

## Features

- Record student attendance
- View attendance records
- Attendance stored in CSV format
- Simple and responsive user interface
- Easy to deploy

---

## Problem Statement

Manual attendance tracking is time-consuming and prone to errors. This project provides a digital solution for recording and managing attendance efficiently.

---

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- CSV (Data Storage)

## How It Works

1. Open the application.
2. Enter student details.
3. Mark attendance.
4. Attendance is saved in `attendance.csv`.
5. View attendance records.

---

## Installation

Clone the repository:

```bash
git clone https://github.com/sumitvarpe21/smart-attendance.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
